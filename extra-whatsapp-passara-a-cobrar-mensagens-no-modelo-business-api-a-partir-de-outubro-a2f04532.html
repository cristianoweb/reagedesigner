Extra - WhatsApp passará a cobrar mensagens no modelo Business API a partir de outubro

Notícias09/09/2026
Design

Notícia do Extra sobre a mudança de cobrança do WhatsApp no modelo Business API a partir de outubro. A cobrança não atinge usuários do WhatsApp Business App, que seguirá gratuito, mas afeta empresas que usam a API para atendimento, automação e mensagens em escala.
